# CampusEats

CampusEats is a campus food ordering system used as the running example for the Web Services course.

This repository contains the work completed for Assignment 1, which focuses on understanding HTTP requests and responses, inspecting network activity using browser Developer Tools, and setting up the CampusEats project repository.

## Assignment 1

The assignment covers:

- Making HTTP requests using `curl`
- Reading HTTP request and response headers
- Understanding HTTP status codes and Content-Type
- Inspecting browser network requests using Developer Tools
- Setting up a Git repository with a clear project structure

## Repository Structure

## Documentation

### HTTP Log

`docs/http-log.md` contains five HTTP request/response examples made using `curl`. The examples include successful GET requests, a deliberate 404 response, and a POST request with a JSON request body.

### Network Analysis

`docs/network-analysis.md` contains an analysis of the network activity observed through the browser Developer Tools Network panel, including the request count, page size, slowest resource, and 3xx/4xx responses.
